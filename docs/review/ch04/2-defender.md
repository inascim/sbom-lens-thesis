- Minimal thesis fix: :10 "the backend holds all graph computation" → "the backend holds the graph analyses". :16 "graph construction, metric calculation, risk assessment, and vulnerability aggregation" → "graph construction, metric calculation, and risk assessment". :220 after "loads them into the Cytoscape instance." add "This conversion is done in the browser by \texttt{convertCycloneDXToGraph()}, which keys nodes by \texttt{bom-ref} only and applies neither the self-loop filter nor the identifier fallback of \autoref{sec:component-extraction}; every component in the evaluation dataset has a \texttt{bom-ref}, so the canvas and the backend graph coincide there."
